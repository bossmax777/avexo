интеграции и API

Кошелёк Avexo открыт наружу: к нему можно подключить торгового робота, сервис сигналов, копитрейдинг или собственный скрипт. Каждая интеграция получает отдельный ключ с ограниченными правами — ключ можно отозвать в любой момент, не трогая остальные.

Ключ REST API Права: чтение счёта, котировки, постановка и снятие ордеров. Без права вывода средств.
