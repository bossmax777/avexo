Вход в кабинет бота

Используйте логин и пароль от кошелька BullWaves. Бот подключается к кошельку по ключу REST API, который выпускается в личном кабинете.

Нет кошелька? Зарегистрируйтесь на сайте BullWaves, затем вернитесь сюда.

Подключение по API

Вставьте ключ REST API из личного кабинета: Профиль → Подключение сторонних торговых помощников → Сгенерировать. Ключ даёт боту право читать счёт и вести сделки, права на вывод средств у него нет.

Нужен ключ вида avx_номер-счёта_… из блока «Ключ REST API». Идентификаторы avx-… из карточек интеграций — это метки подключений, для входа они не подходят. Открыть кабинет
