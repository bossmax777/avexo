# Avexo Trade — учебный демо-макет

Статический одностраничный макет сайта брокера с личным кабинетом.
Вымышленный бренд, все данные условны: счета, котировки, платежи и верификация существуют только внутри страницы.

## Состав

- `index.html` — весь сайт одним файлом (CSS и JS встроены, внешних зависимостей нет, кроме Google Fonts)

## Деплой на Timeweb App Platform

Тип приложения — **Frontend → Статический сайт**:

- Команда сборки: не требуется (оставить пустой)
- Каталог сборки: `.`
- Ветка: `main`
