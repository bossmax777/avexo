# Avexo Trade — учебный демо-макет брокера

Одностраничный сайт брокера с личным кабинетом, админкой и серверным хранением данных.
Вымышленный бренд: счета, платежи и верификация существуют только в рамках макета.

## Состав

- `server.js` — Express: отдаёт статику из `public/` и REST API
- `db.js` — подключение к PostgreSQL и автосоздание схемы при старте
- `public/index.html` — сайт и личный кабинет
- `public/admin.html` — админка

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | строка подключения к PostgreSQL, например `postgresql://user:pass@host:5432/db` |
| `ADMIN_KEY` | ключ для входа в админку, спрашивается один раз за сессию браузера |
| `PORT` | порт приложения, Timeweb подставляет сам |

## Схема базы

- `users` — email, scrypt-хеш пароля, имя, телефон, страна, номер кошелька, валюта, баланс,
  сценарий (`dyn`), позиции, транзакции и история
- `sessions` — токены сессий с датой истечения, чистятся раз в час
- `site_config` — одна строка с настройками сайта из админки

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | состояние сервера и базы |
| POST | `/api/register` | регистрация демо-кошелька |
| POST | `/api/login` и `/api/logout` | вход и выход |
| GET | `/api/me` | текущий пользователь по cookie-сессии |
| PATCH | `/api/me` | правка профиля |
| PUT | `/api/me/state` | баланс, позиции, история кошелька |
| GET | `/api/config` | настройки сайта |
| PUT | `/api/config` | сохранение настроек (нужен `x-admin-key`) |
| GET, POST | `/api/admin/users` | список и создание кошельков |
| PATCH | `/api/admin/users/:id` | начисление, списание, сценарий |
| DELETE | `/api/admin/users/:id` | удаление кошелька |

## Запуск локально

```bash
npm install
DATABASE_URL=postgresql://postgres@localhost:5432/avexo ADMIN_KEY=secret npm start
```

## Деплой на Timeweb App Platform

Тип приложения — **Backend → Node.js**:

- Команда сборки: `npm install`
- Команда запуска: `npm start`
- Переменные: `DATABASE_URL`, `ADMIN_KEY`
- Ветка: `main`

Если сервер недоступен, страницы продолжают работать в локальном режиме на localStorage —
это запасной вариант для показа без интернета.
