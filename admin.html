Настройки сайта Avexo

Здесь меняются тексты лендинга, тарифы, платформы, цифры и оформление. Изменения сохраняются в этом браузере и применяются к сайту сразу после нажатия «Сохранить».

Настройки живут только в вашем браузере на этом домене — на других устройствах сайт покажет значения по умолчанию. Чтобы закрепить их для всех, скачайте JSON и передайте мне: вшью его в репозиторий. Страница без пароля, адрес лучше никому не давать.
